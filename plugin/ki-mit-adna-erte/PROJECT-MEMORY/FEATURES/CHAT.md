# FEATURE — Chat (buyer ↔ seller conversation)

## PURPOSE
A vevő a hirdetésből beszélgetést indít az eladóval, és szabadon írnak, emojit és fájlt küldenek. Csatolmány max. 3 MB, 48 óráig él. A régi ajánlat/deal/értékelés rendszer 2026-10-10-én törölve; helyette újraépül lépésenként. **Kész (2. kör):** a vevő a chatben ajánlatot tesz (összeg). **Kész (3. kör, 2026-10-10):** eladó [Elfogadom] → „Foglalt”, a többi élő ajánlat lezárul + rendszerüzenet, telefonszámok láthatók; [Mégse kelt el] → „Újra elérhető”. **Kész (4. kör, 2026-10-10; átírva az új 1. körben):** eladó [Lezárom] → eladott (hirdetés lezárul, chatek csak olvashatók, „N eladott autó” nő); 7 nap reakció nélkül → `lapsed`: lezárul, de NEM eladás. **Kész (5. kör, 2026-10-10):** vevőnek „Mire figyelj” kép (nagyító), eladónak szerkeszthető adásvételi szerződés aloldal (Word-letöltés + nyomtatás, mentés nélkül). **Kész (6. kör, 2026-10-10):** bejelentés gomb a chat fejlécében → `FEATURES/REPORTS.md`. **Kész (7. kör):** 60 napos lejárat → `LISTINGS.md` „Lejárat”. **Kész (8. kör, 2026-10-10):** vevő [Visszavonom] a saját élő ajánlata alatt (elfogadás után nem); hirdetéstörléskor a chatek olvashatók maradnak („Az eladó törölte a hirdetést.” sáv + mentett cím az Üzenetek listában), Foglalt hirdetésnél rendszerüzenet az elfogadott vevőnek, a törlés nem számít eladásnak.

## SIDE EFFECTS
`kmae_conversation_message_created` → `KMAE_Notifications::on_conversation_message_created` (mail kulcs `message`; szöveg `KMAE_Chat_Offers::message_kind()` szerint: `offer` → „Ajánlatot kaptál” + cheer manó, `offer_retracted` → „Ajánlat visszavonva” + szomorú manó, `dealer_lead` → „Egy kereskedés érdeklődik az autód iránt” + cheer manó, egyéb → „Új üzenet”; a push szövege ugyanígy a `KMAE_Live_Signal::text_for`-ban; a `dealer_lead` a `KMAE_User_Blocks::hides_message`-ben NEM `system` → tiltás után küldve rejtett, mint egy üzenet) + `KMAE_Live_Signal` (jelzőfájl + Web Push). Élő frissítés kontextusok: `conversation_thread`, `messages_inbox`, `single_listing`, `nav_badge` (`KMAE_Live_Page`).

## CHANGE RISKS
Vevő = kék (bal), eladó = narancs (jobb) fix szín. Az inbox fingerprintbe ne kerüljön olvasottság (dupla reload, lásd CLAUDE.md 13). A törölt ajánlat-rendszert ne állítsd vissza részlegesen. A Foglalt/Újra elérhető állapot NEM listing meta/post status (a hirdetés `active` marad; csak a [Lezárom] vagy a 7 napos lezárás teszi `closed`-ra), hanem a `kmae_chat_offers` sorokból származik. Rendszerüzenet-kulcsok: `system:listing_reserved:ID`, `system:listing_reopened:ID` (ID = elfogadott ajánlat; régi chatekben még `system:offer_closed:ID`), `system:offer_accepted:ID`, `system:offer_withdrawn:ID`, `system:listing_deleted:ID`, `system:offer_retracted:ID` (ez a vevő nevében), `system:dealer_lead:<lead id>` (a kereskedő = vevő nevében). A törléskori rendszerüzenetet a `wp_delete_post` ELŐTT kell küldeni (zárt chatbe `save_message` nem ír).
